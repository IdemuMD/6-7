6-7 Pets er en veterinærtjeneste som skal registrere og administrere kjæledyr, eiere og veterinærer. Systemet skal gjøre det mulig for ansatte å opprette, endre, slette og vise informasjon om kunder og kjæledyr.

Databasen bygges i MongoDB og applikasjonen utvikles med Node.js, Express og et webbasert brukergrensesnitt.
